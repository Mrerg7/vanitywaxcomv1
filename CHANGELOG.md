# Changelog — VanityWax.com

## [FEAT]: Comprehensive optimization — 2026-10-06

Stays on **Cloudflare Workers free plan** (static assets + edge `src/worker.ts`, no paid bindings, no server DB).

### I. Technical foundation
- `astro.config.mjs`: `compressHTML`, `inlineStylesheets:auto`, Vite `cssMinify/minify`, sitemap `changefreq/priority/lastmod`, viewport prefetch.
- `public/_headers`: HSTS, nosniff, `X-Frame-Options:DENY`, `Referrer-Policy`, `Permissions-Policy`, CSP (self + fonts + imagedelivery + CF beacon), `Cross-Origin-Opener-Policy`, immutable cache for `/_astro/*`, `must-revalidate` for HTML. `X-Robots-Tag:noindex` for `/index.html` duplicates.
- `public/robots.txt`: allow `/`, sitemap points to `sitemap-index.xml` (generated by `@astrojs/sitemap`).
- `public/manifest.webmanifest`: installable PWA metadata, theme colors.
- `public/_redirects`: collapses `/index.html`, `/home`, `/index`, `/search`, `/sitemap.xml` duplicates.
- `src/worker.ts`: www→apex 301 + HTTPS enforcement before asset lookup (canonical consolidation), `run_worker_first=true` in `wrangler.toml`.
- Canonical: single `https://vanitywax.com/` via layout + SEO OG/Twitter URLs.
- Removed render-blocking Font Awesome CDN — icons are inline SVGs (faster, CSP-friendly).

### II. SEO
- Title format: `VanityWax.com | Premium Domain for Sale | Luxury Body Waxing & Hair Removal Brand`.
- Meta description includes price/availability, CTA, and UVP; added `keywords`, `geo.region/placename`, `author`, `revisit-after`, `google-site-verification`.
- H1 = domain name; H2s = benefits / industry / perfect-for / opportunity / acquire / offer / FAQ / final CTA.
- Internal linking: sticky nav + mobile menu + footer nav (`#why #detail #for #faq #acquire #offer`) + sitemap link.
- Schema.org `@graph`: WebSite (SearchAction) + Organization + WebPage + BreadcrumbList + Product/Offer (InStock, USD, Escrow note) + FAQPage (5 Q&A).
- `SEO.astro` + `StructuredData.astro` components for reusable head/meta/schema.

### III. CRO
